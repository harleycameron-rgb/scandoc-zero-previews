# WaxTablet Scandoc Zero Modular Topology Research Previews 0.1.0

This release candidate packages eight browser previews, a reviewed DOI catalogue and a bounded update display. It is a publication of the research interface stage, not a final demonstrated AGI system.

## Included behaviour

- **Tap:** contact-driven moiré, short sound pulse and explicit hash-chained completed-contact receipts; raw coordinates are not placed in those receipts.
- **Surface:** declared convex-layer classification, sawtooth/wobble screen and sound responses, movement-derived indirect rhythm, bounded transient outputs and optional orientation proxy.
- **Science:** local knowledge-only synthetic comparisons and reset; no external inference or credit gate.
- **Communicate:** virtual memory-only stake, fixed bonuses and reviewed fault compensation; ledger inspection no longer persists credit values to a download.
- **Manifest:** declarations, earlier-entry selection and exportable individual or linked-history evidence.
- **Display:** all-or-nothing single/history import, per-entry inspection and tamper rejection preserving the prior valid view.
- **Harness:** scripted adapters, synthetic planar/sphere views and locally verified Sentinel A/B references. This does not run external LLMs.
- **Navigation:** existing routes retained, with direct module access and scoped DOI evidence.

No exact module-specific benchmark DOI currently certifies the new Surface audio/tilt, credit policy, Manifest schema, Display import UI or navigation. The release verification records local software/browser checks separately.

## Updates and freeze

Setting a benchmark means committing reviewed `site/benchmarks.json` metadata. GitHub Pages regenerates panels after validation. The hub can manually check at most 64 KB or opt into visible-page checks every 15 minutes; no polling starts by default. New metadata never silently swaps a running fixture.

An archive freezes the source and evidence registry. Later website changes do not rewrite the frozen package or an existing DOI. No protected baseline code, private catalogue, uploaded artwork, raw user contacts, keys, credentials or Git history is in the public allowlist.

## Remaining boundaries

Tap and Surface are independent instruments with a shared conceptual core balance, not measured physical coupling. The sphere remains provisional and non-canonical. Hashes are not signatures, anchoring or proof of truth. There is no demonstrated AGI, independent multi-LLM convergence, live actuation, real financial account, physical high-energy-site validation or certified intersample safety.

Physical iPhone audio/tilt remains untested. The website mapping identifies existing-route and receipt-policy differences; this release does not alter waxtablet.co.uk hosting or its server receipt/burn implementation.

## Publication and rights

New-release metadata and archive are prepared for explicit public publication review. The repository's existing rights and upstream notices are preserved; no new blanket license is applied by this candidate. Publication requires confirmation of the proposed release license and authority for included Tap-derived code. Existing Zenodo records and the private verified baseline remain unchanged.

Candidate-state labels in frozen verification documents are preparation history. If this exact package is subsequently published, the public record and separate post-publication verification determine its publication status; the archived files are not silently rewritten.
