## Setting or replacing a benchmark

Edit `site/benchmarks.json`. Keep an exact version DOI, full source commit, explicit scope, publication status and relation to each affected module. A related reference is not an exact reproduction. Do not attach an unpublished DOI as a published record; do not silently replace a source fixture or promote the sphere.

Run:

```sh
node tools/build-evidence.cjs
node tools/check.cjs
```

Commit the registry update to `main`. The existing Pages workflow automatically compiles all eight panels, checks routes/fixtures/receipt integrity, and deploys if checks pass. Setting a benchmark means committing reviewed metadata; a Zenodo edit alone does not silently modify the website. No polling of Zenodo, model reruns, paid inference, repository source download or Perplexity task execution occurs in this path.

## Low-data live display

The hub embeds the last reviewed snapshot and starts with no polling. A manual button reads only the same-origin registry, capped at 64 KB. An optional checkbox enables 15-minute checks only while visible. Conditional ETags are used when supported; errors retain the embedded evidence.

A changed revision displays reviewed DOI links and requests reload. This updates provenance metadata, not simulation state or mathematical truth. The Science app makes no network simulation calls. No update preference, credit value, contact stream or identity is persisted.

## Frozen publication versus current website

A release archive freezes the source, registry, tests and verification report; its DOI remains a version-specific reference. A live site may later show another benchmark revision, but never rewrites the archived package. Release checksums identify bytes, not authorship or physical validation.

The next publication is a research-preview release with an evidence catalogue and scripted orchestration. It is not the final demonstrated AGI system. Production kernel code, private catalogues, original source records, recovery keys and existing Zenodo deposits remain unchanged.
