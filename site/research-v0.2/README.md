# SCANDOC Research Preview v0.2

This is an **additive GitHub staging copy** of the SCANDOC Root Search / Core Expression / MDL topology research direction. It lives under `site/research-v0.2/` and does not replace the existing production site.

The visual labs here are *compact static demonstrations* of the larger local SCANDOC package, not byte-for-byte copies of the full local ZIP. The original local package also contains executable core and MDL test code and reported synthetic test data. Do not equate the static preview with those tests or with authenticated gate operation.

## Publish safely

Review in a pull request first. For Vercel, set Root Directory to `site/research-v0.2` on a distinct preview project or integrate the route into the existing site after review. Do **not** reassign `scandoc-zero.com` or change DNS without confirming project ownership.

No model APIs, visitor analytics, trusted gate service, or write operations. The sentinel is a fixed visualization reference. Six launch faces only; two temporal extensions are post-launch concepts.
